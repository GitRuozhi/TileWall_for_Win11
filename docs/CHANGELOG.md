## V1.55（1.5.5）——2026-11-21

本地开发验证版。

- 新增「导入 Windows 开始屏幕」。新用户在欢迎墙保存并显示后可一键导入，已有用户可从设置发起。Windows 10 保留原组和组内阅读顺序，Windows 11 保留系统固定列表顺序，包括平铺导出的固定文件夹成员。
- 导入按启动身份去重，从第三逻辑栏或现有内容末尾之后追加。可验证的原快捷方式保留启动参数、工作目录和图标。排版按需扩容或减少本批磁贴尺寸，正式墙与受管入口一次保存。
- 欢迎墙以当次核验的原生 Shell 入口生成注册应用磁贴，避免 Windows 返回同应用的磁贴背景色变体时拒绝初始化。开始屏幕导入也按相同的受限条件识别此类重复项。

验证范围：x64 开发构建、二进制和 Core 依赖检查及 37 项定向测试通过。物理 Win10 22H2 从设置导入真实固定项，新增 89 项、去重 3 项、无法解析 1 项。原 13 组的读取顺序及快捷方式抽样摘要核对通过。墙面在容量内扩到 5 栏 23 行，旧组及成员位置保留。重复导入和达到 64 栏上限时的整批拒绝均保持正式快照不变，成功导入项在重开后保留。Win11 26H2 x64 来宾从首次邀请导入 11 个真实固定项，新增 9 项、去重 2 项，设置重试无写入。重开保留组、顺序和受管快捷方式，PowerShell 7 的原始字节、目标、参数和工作目录核对通过。系统导出对照确认样本中固定文件夹成员平铺且齐全。此版验证使用开发程序，范围未包含 MSIX 认证、ARM64 实机或全量 CI。

## [V1.54](https://github.com/GitRuozhi/TileWall_for_Win11/releases/tag/V1.54)（1.5.4）——2026-11-21

GitHub 于 2026-11-21 正式发布，提供 x64 和 ARM64 的便携 ZIP 与 EXE 安装器。

- 资源管理器重建任务栏后自动恢复已启用的开始按钮接管，保留独立的键盘 Win 键通道。
- MSIX 右键菜单按原 `.lnk` 添加快捷方式，保留原名称、启动参数、工作目录和图标。
- 磁贴和拼图编辑器显示文件入口的完整启动命令，可编辑或清空参数。网页、应用协议及系统入口继续按各自的目标类型处理。
- 磁贴墙、菜单式开始及预览的目标悬停提示显示已核验的完整启动命令。只改参数或清空参数，保存后提示立即刷新。
- 正常打开另一分发版本时自动交接已启用、归属可核验的右键菜单。交接失败时目标版本不启用入口，保留可验证的旧入口及失败原因。
- 资源管理器菜单跟随 TileWall 已保存的语言，涵盖 ZIP、EXE 和 MSIX。
- 从设置中关闭右键菜单时，同时停用当前用户已注册的商店菜单并清理可核验的经典菜单及兼容项。无法核验的遗留项保留，并显示路径。
- 修复普通任务栏会撤销主墙原生置顶状态的问题，唤出时保持正确的窗口前后顺序。
- 拖边时系统外观刷新保留当前预览。松手动画对物理边分别取整，固定底沿和右沿不再因插值偏移一像素。
- 主墙的实时 Acrylic、Mica、自定义图片、冻结底图和主题纯色统一由外窗承载。自定义图片保持居中等比填满。
- 菜单式开始随锚点靠左或靠右，并在同一侧给边栏保留固定间距。

本机 Windows 10 22H2 x64 完成 ZIP、EXE、未签名和本地测试签名 MSIX 构建及包检查，104 项定向 Core 用例和输入停止边界检查通过。真实 Explorer 菜单验证了便携与签名 MSIX 的双向交接、未知注册保留及目标开关关闭、切换语言、原快捷方式摘要保留。普通用户安装命令返回了预期的延期状态。实际重启 Explorer 后同一开发实例报告已恢复开始按钮接管。Codex 前台重叠区域命中主墙，关闭持续置顶后主动呼出仍前置，随后失焦按设置收墙。实体 Win 键和实体开始按钮点击未实测，Win11 现代菜单、ARM64 实机、安装回归和商店认证未覆盖。

统一关闭补测使用本机 x64 签名 MSIX 的设置。物理 HKCU 中四个当前经典入口和一个可核验的旧入口已清理，商店开关关闭。指向缺失映像的旧项保留，设置显示其路径。真实 Explorer 文件菜单不再出现 TileWall 项，切回便携版保持关闭。

实时 Acrylic 的快速拖动对照在本机 Windows 10 x64 完成。0.35 和修复前的 V1.54 均出现外窗底沿固定、WinUI 子窗底沿滞后的样本。修复后右下锚点两轮各 96 次快速往返输入均未采到露缝，Esc 恢复尺寸正常。左下锚点跨格松手后固定底沿坐标，保存成功。

统一外窗后在本机 Windows 10 x64 验证了实时 Acrylic、自定义图片、冻结底图的失焦与重新激活，以及 Mica 不可用时的纯色回退。自定义图片经过文件选择、重启和上下快拖，快速横拖仍有偶发短帧露底。纯色回退在两轮横向快拖未采到露缝。菜单列在左右锚点均按同侧边栏留出 48 DIP，右锚定时按住左沿扩大 84 像素，菜单仍贴右侧栏，悬停侧栏可展开覆盖。Win11 原生 Mica 未做实机验证。

目标编辑补测在同一 Windows 10 x64 环境完成。现有 AutoCAD 磁贴显示完整命令，确认后取消保留受管入口字节。测试磁贴修改参数后重开能读回，实际启动保留参数中的空格和特殊字符，并使用原工作目录。清空参数后重开显示文件路径。普通文件、目录、网页、应用协议、原生 Shell 和空目标的编辑页显示均实测。39 项定向 Core 测试通过。

目标悬停补测核对了 AutoCAD 磁贴的实际弹出提示和菜单式开始的目标文本。测试磁贴仅修改参数和清空参数后，悬停提示均在同一实例中立即刷新。编辑预览的悬停提示显示了已确认的草稿命令。13 项相关 Core 测试通过。
