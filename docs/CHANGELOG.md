# 更新日志

本页记录对外版本状态、功能变化、兼容性、已知限制和必要验证范围。[GitHub Releases](https://github.com/GitRuozhi/TileWall/releases)提供正式下载；源码与构建说明见[开发者指南](DeveloperGuide.zh-CN.md)。GitHub发行与Microsoft Store上架状态分别以对应页面为准。

## V1.60（1.6.0）

2026-11-26 完成开发和 x64 便携构建。

- 「设置 → 关于」在反馈下方提供「初始化」和「数据」。可打开本次运行的日志及用户数据目录，也可确认清空共用数据并重启当前发行版。「显示不可用控件」移到「系统」，原有设置随保存保留。
- 普通分组标题的右键菜单可重命名、批量编辑及确认后将整组移入回收站。设置新增独立的分组菜单配置。旧设置缺少该字段时默认启用全部分组命令，持久格式版本沿用原值。
- 批量页可选择和重排本组成员，统一修改适用属性，或逐项处理目标、标题和前景。预览中的改动在整批校验后一次保存，取消选中的成员仍保留其草稿。普通磁贴改尺寸后按组内顺序重排。
- 导入和导出、编辑、批量编辑共用默认页面宽度与预览栏宽度。三页打开时在工作区内定高，切换选项、展开明细时保持高度，内容在栏内滚动，操作卡固定在右下角，均可拖边调整。
- 批量页按标题展开，左栏固定显示「已选数/总数」。右栏的「编辑」卡提供撤销、重做、全选和全不选，批量属性值不同时在卡片右侧显示高亮的「混合」标签。明细左侧的成员标题与首行控件对齐，超长时显示省略号。普通磁贴的大小提供四种预设。「全部取消固定」确认框只列磁贴标题。

通过 52 项定向 Core 用例及八语新增资源检查。物理 Windows 10 22H2 x64 实测两个目录入口、设置保存重开、隔离数据完全重置的取消、确认重启及重解析点拒绝，以及组内框选、拖动、混合编辑保存重开、重复目标拒绝、取消和整组回收。本版实测使用 x64 便携开发版。

界面修正后在同一环境核对整组确认文案，以及行内目标、标题、图片与批量透明度的保存。实测三页默认尺寸、切换导入导出模式和磁贴类型、展开批量明细时的高度，以及拖边后保持手动尺寸和栏内滚动。核对批量选择计数、标题／目标／尺寸撤销与重做，以及三页操作卡在右栏滚动时保持可见。

## V1.59（1.5.9）

2026-11-25 开发结项。x64 和 ARM64 的 EXE 安装器、便携 ZIP 及未签名商店 MSIX 已完成构建和本地包检查。结项时，GitHub 尚无 V1.59 Release。

- 设置中「系统」紧随「唤出」。「背景」「背景透明度」「背景网格」移到「个性」。「初始后景」位于「初始大小」前，与编辑页共用后景选项和颜色选择器。
- 新建或从来源导入的普通自动图标磁贴采用初始后景。编辑中的显式选择优先，拼图、图片、相册、墙包和恢复对象沿用各自的外观规则。旧设置缺少该字段时使用「初始」，快照和墙包格式版本沿用现有版本。
- 「设置 → 关于」可打开本会话的日志目录。每批普通导入或一键导入都有独立的操作标识，用于关联来源统计、布局和提交终态。详细阶段沿用 INFO 开关，失败摘要记录操作分类和计数。
- 主墙完全收起并连续空闲 30 秒后，每次隐藏可进行一次后台 CLR 堆回收。工作仍在途时延后，唤出和退出会取消尚未开始的回收。见 [Issue #6](https://github.com/GitRuozhi/TileWall/issues/6)。

x64 开发构建、143 项定向 Core 用例及八语资源检查通过。物理 Windows 10 22H2 x64 实测 G03、G09、设置顺序、选色与重开读回、新建及图片外观、日志目录与不可用提示、普通及一键导入和确认前取消。用定向检查核对导入终态的级别、分类和去重。

同机同一面 80 磁贴毛玻璃墙上，私有提交从 299.70 MiB 降至 184.42 MiB，私有工作集从 239.48 MiB 降至 120.54 MiB。提前唤出、回收后唤出、与回收重叠时，热键到屏幕首帧分别为 91.13、99.43、103.48 毫秒，各取一个样本。实测后台来源工作完成后约 30 秒才开始回收，同一隐藏周期只回收一次，提前唤出和退出均取消待执行的回收。墙面内容和显示帧在再次唤出后完整。Win11、原生 ARM64 运行、安装和升级未覆盖。
