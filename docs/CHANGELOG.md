## V1.52（1.5.2，本地候选）——2026-11-14

尚未公开发布或提交商店。

- 保留x64并新增ARM64原生分发，两架构分别提供便携ZIP、EXE安装器和商店上传用未签名MSIX；商店为同一产品准备两份包，一览仍仅中英两种。
- 应用及安装器支持英语、简中、繁中、日、韩、德、法、西语；设置保留跟随系统，支持语言族匹配和逐键英文回退。系统功能目录、菜单、通知及启动早期自有消息同步覆盖八语，用户标题、路径和已有组名不因切语改变。
- 修复切换语言后侧栏及菜单投影仍显示上一次语言的问题，尺寸子菜单打开时同步刷新；缩短德语导入导出按钮文案以避免裁切。
- 正式数据根清单与settings格式由5升级到6，保留原语言枚举0／1／2，新增值为3至8。旧数据通过既有联合事务一次升级，保留布局、设置、资源和回收内容；旧版本遇到新格式阻断并保留现场，不回写降级。墙内容、分享包与journal协议未变。
- 构建入口增加 `-Architecture x64|arm64|All`，组合构建检查完成后一次交付六包，日常开发目录继续使用同源x64程序；依赖版本、正式身份、数据根与单实例合同保持不变。

验证范围：八语各866项的资源键、非空值、格式占位符及MRT／manifest声明检查通过；本机直接相关Core用例65例通过，未重复运行完整Core。x64／ARM64六包编译、架构、原生安全、内容及运行时依赖检查通过。本机Windows 10真实x64开发版完成八语主墙／设置切换、德语编辑及导入导出页面查看与取消、语言保存重开；v5旧数据升级至6后墙内容与回收内容摘要不变。抽查德语安装器并取消。未新增完整GUI套件、安装／升级／卸载、签名、WACK或Win11矩阵；ARM64原生运行及安装尚未实测。私有远端CI已触发，状态独立于本地交付，不以排队或运行中阻塞交付。

## [V1.51](https://github.com/GitRuozhi/TileWall_for_Win11/releases/tag/V1.51)（1.5.1）——2026-11-14

GitHub正式发布，提供自包含便携ZIP和EXE安装器。

- 补充了开发者指南和许可证，完善了 TileWall 的开源贡献。
- 对仓库结构进行了完整重新整理，对文档进行了系统性整治，大幅降低了屎山堆积风险。
- 增加墙面缩放松手后的格子吸附过渡动画，让尺寸调整更加自然。
- 缩放结束时显示当前栏数、行数，并增加磁贴／分组移动及全屏、拓展栏位切换的操作提示。
- 修复图集目录路径末尾带有 `\` 或 `/` 时被错误拒绝的问题。
- 修复导入含图集的墙包时，原图可能未正确准备的问题。
- 修复解锁布局后，跨组移走最后一个成员时，原分组占位未保留的问题。
- 修复名称以 `.lnk` 或 `.url` 结尾的真实文件夹无法使用“打开位置”的问题。
- 修正通过 Windows Shell 提取图标时使用的像素尺寸。

验证范围：Core 1634通过、0失败、0跳过；发行包构建、内容和依赖检查通过。功能开发阶段在Windows 10完成缩放、操作提示及保存重开的定向GUI检查；最终附件未新增GUI、安装／升级、签名或WACK验收，也未新增Win11系统矩阵验证。
