## **Reprenez vie, mes vignettes !**

**TileWall** est un lanceur de vignettes indépendant qui fait revivre l’expérience familière des vignettes et du menu Démarrer de Windows 10 sous Windows 11, avec des images, des albums et des puzzles à personnaliser.

**TileWall** est développé avec WinUI 3, le framework d’interface natif de Windows. Il réinvente le menu Démarrer et le mur de vignettes. Par défaut, le raccourci **Win + la touche accent grave** (à gauche du 1 sur un clavier américain, sans maintenir Maj) affiche le mur, indépendamment du menu Démarrer de Windows. Tu n’as pas besoin de remplacer le shell Windows ni de changer tes habitudes.

TileWall prend en charge Windows 10 22H2 (build 19045) et Windows 11 sur les PC x64. L’interface de l’application est disponible uniquement en chinois simplifié et en anglais ; les captures ci-dessous montrent l’interface anglaise.

## Puzzles, images et albums

Plus besoin de découper et d’aligner les images à la main : tout se fait sur une seule page !

Clique sur Split tiles, puis sur les pointillés de l’aperçu avec le bouton gauche ou droit pour découper ou fusionner des zones. Fais défiler la molette pour régler rapidement le zoom de l’image.

Définis une image comme cible : **TileWall** active automatiquement les vignettes illustrées.

Définis comme cible un dossier contenant des images compatibles : **TileWall** active automatiquement la rotation de l’album. Ajoute ou supprime des images dans le dossier, et **TileWall** met l’album à jour automatiquement.

Tu peux aussi personnaliser l’apparence d’une vignette de raccourci classique avec une image ou un album.

## Retrouvez l’expérience du menu Démarrer de Windows 10

Appuie sur <kbd>Win</kbd> + la touche accent grave (à gauche du 1 sur un clavier américain, sans Maj) pour faire apparaître le mur de vignettes. Lance un programme avec succès ou déplace le focus ailleurs : le mur se replie automatiquement, comme le menu Démarrer natif.

Pour garder le mur sur le bureau comme une application classique, désactive Always on top et active Stay visible.

Fais glisser les vignettes pour les déplacer, ou le titre d’un groupe pour déplacer tout le groupe. Tout est fluide, avec le comportement du menu Démarrer natif.

Fais glisser le bord du mur pour le redimensionner. Fais-le glisser jusqu’au bord de l’écran pour passer sans accroc du mode plein écran au mode fenêtré.

Les quatre coins du bureau peuvent servir de points d’ancrage, pour encore plus de liberté qu’avec le menu Démarrer natif.

Tu peux aussi activer Replace system Start dans Settings. L’option est désactivée par défaut. Une fois activée, la touche Windows ou le bouton Démarrer permet d’afficher TileWall ; tu peux revenir au menu Démarrer natif quand tu veux.

## Plus de fonctionnalités

Les vignettes peuvent ouvrir des fichiers, des dossiers, des raccourcis et des sites Web, ainsi que des liens de protocole d’application enregistrés dans Windows, comme ceux de Steam.

Place tes programmes, dossiers, fichiers et sites Web sur le même mur pour en faire ton lanceur personnalisé.

Tu peux ajouter des vignettes avec le menu contextuel du mur ou le menu contextuel classique de l’Explorateur de fichiers.

Envie de tout organiser rapidement ? La page d’importation permet d’ajouter des vignettes depuis le menu Démarrer, le bureau, les applications installées, les fonctionnalités système et des fichiers de mur. Les filtres, le filtrage automatique et le regroupement t’évitent de tout ajouter un par un avec le menu contextuel.

Tu peux exporter les vignettes, puzzles et albums sélectionnés dans un fichier ZIP à partager.

Les vignettes désépinglées vont dans la corbeille et peuvent être restaurées si besoin.

Le menu Démarrer te manque aussi ? Active Start menu list dans Settings : la liste et les vignettes s’affichent côte à côte et donnent accès aux mêmes éléments.
