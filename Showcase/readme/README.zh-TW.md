## **復活吧！我的動態磚！**

**TileWall** 是一款專為 Windows 11 打造的獨立動態磚啟動牆，重現 Windows 10 熟悉的動態磚體驗，同時支援 Windows 10 和 11。

熟悉的動態磚、群組、拖放和快捷鍵呼出，加上更自由的圖片、相簿與拼圖玩法，**TileWall** 讓你的那面牆擁有更多可能。

**TileWall** 使用 Windows 原生介面框架 WinUI 3 開發，重寫了開始功能表和動態磚牆，預設按 **Win + ~** 呼出，獨立執行，完全不依賴 Windows 系統工作列。Windows 的屎山我受夠了。（劃掉）



## 拼圖、圖片與相簿

不必再自行分割和對齊圖片，一個頁面就能搞定全部！

點選繪製，在預覽的虛線上按左鍵或右鍵即可分割與合併；滾動滑鼠滾輪就能快速調整圖片縮放。

把圖片設為目標，**TileWall** 會自動啟用圖片動態磚；

把含有可用圖片的資料夾設為目標，**TileWall** 會自動啟用相簿切換；在資料夾中新增或移除圖片，**TileWall** 會自動更新相簿。

一般的捷徑動態磚也能自訂外觀，改用圖片或相簿。

## 重現 Windows 10 開始功能表體驗

按下 <kbd>Win</kbd> + <kbd>~</kbd>，動態磚牆就會出現。開啟程式或把焦點切到別處，動態磚牆會自動收起，動作與原生開始功能表一致。

想讓它像一般軟體一樣留在桌面上，可以關閉永遠置頂、開啟常駐顯示。

拖動動態磚調整位置，拖動群組標題即可移動整組。操作滑順俐落，動作與原生開始功能表一致。

拖曳動態磚牆邊緣可以調整大小，拖曳到螢幕邊緣還可以無縫切換全螢幕／視窗模式。

桌面四個角落都能作為錨點，比原生更自由。

## 更多功能

動態磚支援多種啟動方式，包括檔案、資料夾、捷徑、網站，以及 Steam 等已在系統中註冊的應用程式通訊協定連結。

你可以把各種程式、資料夾、檔案和網站放到同一面牆上，打造專屬的完整入口。

同時支援從動態磚牆右鍵選單和檔案總管的傳統右鍵選單建立動態磚。

想快速布置？匯入頁面支援從多種來源匯入動態磚，自動篩選和分組，不必再一個一個從右鍵選單新增。（匯入開始功能表已完成，更多來源正在開發中）
