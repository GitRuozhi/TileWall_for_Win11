## **復活吧！我的動態磚！**

**TileWall** 是一款獨立的動態磚啟動牆，提供個人化的圖片、相簿與拼圖玩法，在 Windows 11 上重現 Windows 10 熟悉的動態磚與開始功能表體驗。

支援 Windows 10 與 Windows 11，適用於 x64 電腦，提供簡體中文與英文介面。

**TileWall** 使用 Windows 原生介面框架 WinUI 3 開發，重現開始功能表與動態磚牆；預設按下 **Win + 反引號鍵** 即可呼叫，並與系統開始功能表各自獨立。不必取代 Windows Shell，也不必改變原有的使用習慣。

可以透過[**Microsoft Store**](https://apps.microsoft.com/store/detail/9NZZN35FDB0C?cid=DevShareMCLPCS)安裝，也可以下載[可攜壓縮包](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest)或 [EXE 離線安裝包](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest)。可攜版解壓後即可執行，三種發佈方式共用目前使用者的動態磚牆資料，資料位置為 `%LOCALAPPDATA%\TileWall`。


## 拼圖、圖片與圖集

不用再自行分割、對齊圖片，一個頁面就能搞定所有事情！

將圖片設為目標， **TileWall** 會自動啟用圖片動態磚；

將含有可用圖片的資料夾設為目標， **TileWall** 會自動啟用圖集切換；在資料夾中新增或移除圖片，**TileWall** 也會自動更新圖集，不必在編輯頁面修改。

一般捷徑動態磚也能自訂外觀，改用圖片或圖集。

在拼圖模式中，於預覽內部的格線上按滑鼠左鍵或右鍵即可分割或合併；滾動滑鼠滾輪就能快速調整圖片縮放。

## 重現 Windows 10 開始功能表體驗

按下 <kbd>Win</kbd> + <kbd>&#96;</kbd>（數字 1 左側的按鍵，無需 Shift），動態磚牆就會出現。預設情況下，成功啟動目標或將焦點切換到別處後，動態磚牆會自動收起。

想讓它像一般軟體一樣留在桌面上，可以關閉「永遠置頂」，並開啟常駐顯示。

拖動動態磚可調整位置，拖動群組標題即可移動整組，依照自己的習慣布置這面牆。

拖曳動態磚牆邊緣可以調整視窗大小，也可以在設定中切換全螢幕與視窗模式。全螢幕時，向內拖曳可調整的邊緣或角落，即可回到視窗模式。

桌面四個角落都能作為錨點，比原生更自由。

布置滿意後，可以在設定中開啟**版面鎖定**，固定牆面可見大小、錨點與群組位置。單一動態磚仍可移至既有群組內放得下的空位，不會擠動其他內容；重新啟動後也會維持鎖定。

也可以在設定中開啟**取代系統開始（實驗）**，用 Windows 鍵或點擊開始按鈕呼叫 TileWall；隨時都能關閉此選項，恢復原生開始功能表的入口。

## 更強大的功能

動態磚支援檔案、資料夾、捷徑、網站等多種啟動方式，以及 Steam 等已在系統中註冊的應用程式通訊協定連結。

你可以把任意程式、目錄、檔案、網站放在同一面牆上，打造專屬的完整入口。

也支援從動態磚牆的右鍵選單及檔案總管的傳統右鍵選單建立動態磚。

自動圖示支援讀取程式、捷徑與應用程式套件中的原生高解析度資源，並依顯示需求選用合適尺寸；常用網站也有隨套件提供的離線圖示。喜歡自己的搭配，也可以隨時手動更換圖片。

想快速布置？匯入頁面支援從開始功能表、桌面、已安裝的應用程式、系統功能與牆面檔案批次新增動態磚，也支援篩選、自動過濾與群組，不必再逐一按右鍵新增。

支援將選取的動態磚、拼圖與圖集匯出為 ZIP 分享檔案，也可以匯入他人分享的動態磚牆。

取消釘選的動態磚會進入 TileWall 資源回收筒，需要時可以從「匯入與匯出 → 資源回收筒」選擇還原。

如果你也懷念開始功能表，可以在設定中開啟**清單式開始功能表**。清單與動態磚會並排顯示，兩邊都能存取同一批項目。
