## **復活吧！我的動態磚！**

**TileWall** 是一款獨立的動態磚啟動牆，提供個人化的圖片、相簿與拼圖玩法，在 Windows 11 上重現 Windows 10 熟悉的動態磚與開始功能表體驗。

**TileWall** 使用 Windows 原生介面框架 WinUI 3 開發，重現開始功能表與動態磚牆；預設按下 **Win + 反引號鍵（無需 Shift）** 即可呼叫，並與系統開始功能表各自獨立。不必取代 Windows Shell，也不必改變你原有的使用習慣。

支援 Windows 10 22H2（build 19045）與 Windows 11，適用於 x64 電腦。應用程式介面僅提供簡體中文與英文。


## 拼圖、圖片與圖集

不必再自行分割和對齊圖片，一個頁面就能搞定所有事情！

點選「Split tiles（分割磁貼）」，在預覽的虛線上按左鍵或右鍵即可分割與合併；滾動滑鼠滾輪就能快速調整圖片縮放。

將圖片設為目標，**TileWall** 會自動啟用圖片動態磚；

將含有可用圖片的資料夾設為目標，**TileWall** 會自動啟用圖集切換；在資料夾中新增或移除圖片，**TileWall** 也會自動更新圖集。

一般捷徑動態磚也能自訂外觀，改用圖片或圖集。

## 重現 Windows 10 開始功能表體驗

按下 <kbd>Win</kbd> + <kbd>&#96;</kbd>（數字 1 左側的按鍵，無需 Shift），動態磚牆就會出現。成功啟動目標後或失去焦點時，動態磚牆會自動收起，行為與原生開始功能表一致。

想讓它像一般軟體一樣留在桌面上，可以關閉永遠置頂、開啟常駐顯示。

拖動動態磚可調整位置，拖動分組標題即可移動整組。操作流暢，行為與原生開始功能表一致。

拖曳動態磚牆邊緣可以調整大小；拖曳到螢幕邊緣，還能無縫切換全螢幕／視窗模式。

桌面四個角落都能作為錨點，比原生更自由。

還可以在設定中開啟取代系統開始，用 Windows 鍵或開始按鈕呼叫 TileWall；隨時都能切回原生開始功能表。

## 更多功能

動態磚支援檔案、資料夾、捷徑、網站等多種啟動方式，以及 Steam 等已在系統中註冊的應用程式通訊協定連結。

你可以把任意程式、目錄、檔案、網站放到同一面牆上，打造專屬的完整入口。

同時支援從動態磚牆的右鍵選單，以及檔案總管的傳統右鍵選單建立動態磚。

想快速布置？匯入頁面支援從開始功能表、桌面、已安裝應用程式、系統功能及牆面檔案批次新增動態磚，也支援篩選、自動過濾與分組，不必再逐一按右鍵新增。

支援將選取的動態磚、拼圖與圖集匯出為分享檔案。

取消釘選的動態磚會進入資源回收筒，需要時可以還原。

如果你也懷念開始功能表，可在設定中開啟 **Start menu list（開始功能表清單）**。清單與動態磚會並排顯示，兩邊都能存取同一批項目。
