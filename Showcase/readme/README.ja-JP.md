## **よみがえれ！わがタイルよ！**

**TileWall** は、画像、アルバム、パズルを自分好みに楽しめる独立型タイルランチャーです。Windows 11 で、Windows 10 でおなじみのタイルとスタートメニューの使い心地を再現します。

**TileWall** は Windows 標準の UI フレームワーク WinUI 3 で開発されています。スタートメニューとタイルウォールを再現し、既定では **Win + バッククォートキー（Shift 不要）** で表示できます。システムのスタートメニューとは独立して動作します。Windows Shell を置き換える必要はなく、これまでの使い方を変える必要もありません。

Windows 10 22H2（build 19045）と Windows 11 に対応し、x64 PC 向けです。アプリの UI は簡体字中国語と英語のみです。


## パズル、画像、アルバム

画像を自分で分割して位置を合わせる必要はもうありません。すべてをひとつのページで設定できます！

「Split tiles（タイルを分割）」をクリックし、プレビューの点線を左クリックまたは右クリックすると、区画を分割／結合できます。マウスホイールを回すと、画像の拡大率をすばやく調整できます。

画像をターゲットに設定すると、**TileWall** が自動で画像タイルを有効にします。

対応する画像を含むフォルダーをターゲットに設定すると、**TileWall** が自動でアルバム切り替えを有効にします。フォルダー内の画像を追加または削除すると、アルバムも自動で更新されます。

通常のショートカットタイルも、画像やアルバムで見た目をカスタマイズできます。

## Windows 10 のスタートメニューを再現

<kbd>Win</kbd> + <kbd>&#96;</kbd>（数字の 1 キーの左隣にあるキー。Shift キーは不要）を押すと、タイルウォールが表示されます。プログラムの起動に成功した後、または別の場所にフォーカスが移ると、ネイティブのスタートメニューと同じようにウォールが自動で折りたたまれます。

通常のアプリのようにデスクトップに表示したままにするには、「常に手前に表示」をオフにし、「常駐表示」をオンにします。

タイルをドラッグして位置を変えたり、グループ名をドラッグしてグループ全体を移動したりできます。滑らかに動き、ネイティブのスタートメニューと同じ動作をします。

タイルウォールの端をドラッグするとサイズを変更できます。画面の端までドラッグすると、全画面表示とウィンドウ表示をシームレスに切り替えられます。

デスクトップの四隅をアンカーとして使え、ネイティブより自由に配置できます。

設定で「システムのスタートを置き換える」を有効にすると、Windows キーやスタートボタンから TileWall を呼び出せます。いつでもネイティブのスタートメニューに戻せます。

## さらに便利な機能

タイルから、ファイル、フォルダー、ショートカット、Web サイトのほか、Steam などシステムに登録されたアプリプロトコルリンクも開けます。

プログラム、フォルダー、ファイル、Web サイトを同じウォールにまとめ、自分だけのランチャーを作れます。

ウォールの右クリックメニューからも、エクスプローラーの従来の右クリックメニューからもタイルを作成できます。

手早く設定したいですか？インポートページでは、スタートメニュー、デスクトップ、インストール済みアプリ、システム機能、ウォールファイルからタイルをまとめて追加できます。フィルター、自動除外、グループ分けにも対応しており、右クリックで一つずつ追加する必要はありません。

選択したタイル、パズル、アルバムを共有ファイルとしてエクスポートできます。

ピン留めを外したタイルはごみ箱に入り、必要なときに復元できます。

スタートメニューが恋しい方は、設定で**Start menu list（スタートメニューリスト）**を有効にしてください。リストとタイルが並んで表示され、どちらからも同じ項目にアクセスできます。
