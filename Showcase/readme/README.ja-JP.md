## **蘇れ！我がタイルよ！**

**TileWall** は、Windows 11 向けに作られた独立型のタイルランチャーです。Windows 10 でおなじみのタイル体験を再現し、Windows 10 と 11 の両方に対応します。

おなじみのタイル、グループ、ドラッグ＆ドロップ、ショートカットキーでの呼び出しに加え、画像、アルバム、パズルをもっと自由に楽しめます。**TileWall** で、あなたのタイルウォールの可能性が広がります。

**TileWall** は Windows 標準の UI フレームワーク WinUI 3 で開発され、スタートメニューとタイルウォールを作り直しました。既定では **Win + ~** で呼び出せます。Windows のタスクバーに依存せず、単独で動作します。Windows のスパゲッティコードにはもううんざりです。（今のなし）



## パズル、画像、アルバム

画像を手作業で分割して位置合わせする必要はもうありません。すべてをひとつのページで完結できます！

「描画」をクリックし、プレビューの点線を左クリックまたは右クリックすると、区画を分割／結合できます。マウスホイールを回すと、画像の拡大率をすばやく調整できます。

画像をターゲットに設定すると、**TileWall** が自動的に画像タイルを有効にします。

対応する画像が入ったフォルダーをターゲットに設定すると、**TileWall** が自動でアルバム切り替えを有効にします。フォルダー内の画像を追加または削除すると、アルバムも自動で更新されます。

通常のショートカットタイルも、画像やアルバムで見た目をカスタマイズできます。

## Windows 10 のスタートメニューを再現

<kbd>Win</kbd> + <kbd>~</kbd> を押すと、タイルウォールが表示されます。プログラムを開くか、ほかの場所にフォーカスを移すと、ネイティブのスタートメニューと同じようにウォールが自動で折りたたまれます。

通常のアプリのようにデスクトップに表示したままにするには、「常に手前に表示」をオフにし、「常駐表示」をオンにします。

タイルをドラッグして並べ替えたり、グループ名をドラッグしてグループ全体を移動したりできます。操作は滑らかで、ネイティブのスタートメニューと同じ動きです。

タイルウォールの端をドラッグするとサイズを変更できます。画面の端までドラッグすると、全画面表示とウィンドウ表示をシームレスに切り替えられます。

デスクトップの四隅をどこでもアンカーにでき、ネイティブのスタートメニューより自由に配置できます。

## さらに便利な機能

タイルからファイル、フォルダー、ショートカット、Webサイトに加え、Steam リンクなど Windows に登録されたアプリプロトコルリンクも開けます。

プログラム、フォルダー、ファイル、Webサイトを同じウォールにまとめて、自分だけの総合ランチャーを作れます。

ウォールの右クリックメニューからも、従来のエクスプローラーのコンテキストメニューからもタイルを作成できます。

手早く設定したいですか？インポートページでは複数のソースからタイルを取り込めます。自動で絞り込みとグループ分けを行うので、右クリックメニューから一つずつ追加する手間が省けます。（スタートメニューからのインポートは対応済みで、ほかのソースは開発中です。）
