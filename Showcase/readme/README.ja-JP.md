## **よみがえれ！わがタイルよ！**

**TileWall** は、画像、アルバム、パズルを自分好みに楽しめる独立型タイルランチャーです。Windows 11 で、Windows 10 でおなじみのタイルとスタートメニューの使い心地を再現します。

Windows 10 と Windows 11 に対応し、x64 PC 向けです。アプリの UI は簡体字中国語と英語に対応しています。

**TileWall** は Windows 標準の UI フレームワーク WinUI 3 で開発されています。スタートメニューとタイルウォールを再現し、既定では **Win + バッククォートキー** で表示できます。システムのスタートメニューとは独立して動作します。Windows Shell を置き換える必要はなく、これまでの使い方を変える必要もありません。

[**Microsoft Store**](https://apps.microsoft.com/store/detail/9NZZN35FDB0C?cid=DevShareMCLPCS)からインストールするか、[ポータブル圧縮ファイル](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest)または [EXE オフラインインストーラー](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest)をダウンロードできます。ポータブル版は展開後すぐに実行でき、3種類の配布方法で現在のユーザーのタイルウォールデータを共有します。データの保存先は `%LOCALAPPDATA%\TileWall` です。


## パズル、画像、アルバム

画像を自分で分割して位置を合わせる必要はもうありません。すべてをひとつのページで設定できます！

画像をターゲットに設定すると、**TileWall** が自動で画像タイルを有効にします。

使用可能な画像を含むフォルダーをターゲットに設定すると、**TileWall** が自動でアルバムの切り替えを有効にします。フォルダー内の画像を追加または削除すると、**TileWall** が編集ページを変更することなくアルバムを自動で更新します。

通常のショートカットタイルも、画像やアルバムで見た目をカスタマイズできます。

パズルモードでは、プレビュー内のグリッド線を左クリックまたは右クリックして分割／結合できます。マウスホイールを回すと、画像の拡大率をすばやく調整できます。

## Windows 10 のスタートメニューを再現

<kbd>Win</kbd> + <kbd>&#96;</kbd>（数字の 1 キーの左隣にあるキー。Shift キーは不要）を押すと、タイルウォールが表示されます。既定では、タイルの起動先を正常に開くか、別の場所にフォーカスを移すと、ウォールが自動で折りたたまれます。

通常のアプリのようにデスクトップに表示したままにするには、「常に手前に表示」をオフにして、「常駐表示」をオンにします。

タイルをドラッグして位置を変えたり、グループ名をドラッグしてグループ全体を移動したりできます。自分の使い方に合わせてウォールを配置しましょう。

タイルウォールの端をドラッグするとウィンドウのサイズを変更できます。設定から全画面表示とウィンドウ表示を切り替えることもできます。全画面表示のときに、サイズ変更できる端や角を内側へドラッグするとウィンドウ表示に戻ります。

デスクトップの四隅をアンカーとして使え、標準より自由に配置できます。

配置が決まったら、設定で**レイアウトロック**を有効にすると、ウォールの表示サイズ、アンカー、グループ位置を固定できます。個々のタイルは、ほかの内容を動かさずに、既存のグループ内にある十分な広さの空きスペースへ移動できます。再起動後もロック状態が維持されます。

設定で**システムのスタートメニューを置き換える（実験）**を有効にすると、Windows キーまたはスタートボタンから TileWall を呼び出せます。この設定はいつでもオフにして、標準のスタートメニューへの入口に戻せます。

## さらに便利な機能

タイルから、ファイル、フォルダー、ショートカット、Web サイトのほか、Steam などシステムに登録されたアプリプロトコルリンクも開けます。

プログラム、フォルダー、ファイル、Web サイトを同じウォールにまとめ、自分だけのランチャーを作れます。

タイルウォールの右クリックメニューと、エクスプローラーの従来の右クリックメニューの両方からタイルを作成できます。

自動アイコン機能は、プログラム、ショートカット、アプリパッケージに含まれるネイティブの高解像度リソースを読み取り、表示に合ったサイズを選びます。よく使われる Web サイトには、パッケージに同梱されたオフラインアイコンもあります。好みの画像を手動で選ぶこともできます。

すばやく設定したいですか？インポートページでは、スタートメニュー、デスクトップ、インストール済みアプリ、システム機能、ウォールファイルからタイルをまとめて追加できます。フィルター、自動除外、グループ分けにも対応しており、右クリックで一つずつ追加する必要はありません。

選択したタイル、パズル、アルバムを共有用の ZIP ファイルとしてエクスポートでき、ほかの人が共有したタイルウォールをインポートすることもできます。

ピン留めを外したタイルは TileWall のごみ箱に入り、必要なときは「インポートとエクスポート → ごみ箱」から復元できます。

スタートメニューが恋しい方は、設定で**リスト形式のスタートメニュー**を有効にしてください。リストとタイルが並んで表示され、どちらからも同じ項目にアクセスできます。
