## 되살아나라! 나의 타일이여!

**TileWall**은 Windows 11을 위해 만든 독립형 타일 런처로, 익숙한 Windows 10 타일 경험을 되살리면서 Windows 10과 11을 모두 지원합니다.

익숙한 타일, 그룹, 끌어서 놓기, 단축키로 타일 벽 불러오기, 그리고 그림·앨범·퍼즐을 더 자유롭게 즐기는 기능까지. **TileWall**로 나만의 타일 벽을 더 다양하게 꾸며 보세요.

**TileWall**은 Windows의 네이티브 UI 프레임워크인 WinUI 3로 개발했습니다. 시작 메뉴와 타일 벽을 새로 만들었으며, 기본적으로 **Win + ~**를 누르면 나타나고 Windows 작업 표시줄에 전혀 의존하지 않고 독립적으로 실행됩니다. Windows의 스파게티 코드에는 이제 질렸어요. (방금 말은 취소.)



## 퍼즐, 그림과 앨범

이제 그림을 직접 자르고 맞출 필요 없이, 한 페이지에서 모두 해결하세요!

그리기를 누른 다음 미리 보기의 점선에서 마우스 왼쪽이나 오른쪽 버튼을 클릭하면 영역을 나누거나 합칠 수 있습니다. 마우스 휠을 굴려 그림 확대율을 빠르게 바꿔 보세요.

그림을 대상으로 설정하면 **TileWall**이 자동으로 그림 타일을 사용합니다.

지원되는 그림이 있는 폴더를 대상으로 설정하면 **TileWall**이 자동으로 앨범 전환을 켭니다. 폴더에 그림을 추가하거나 삭제하면 **TileWall**이 앨범을 자동으로 업데이트합니다.

일반 바로 가기 타일도 그림이나 앨범으로 모양을 바꿀 수 있습니다.

## Windows 10 시작 메뉴 경험 재현

<kbd>Win</kbd> + <kbd>~</kbd>를 누르면 타일 벽이 나타납니다. 프로그램을 열거나 다른 곳으로 포커스를 옮기면 타일 벽이 자동으로 접혀 들어갑니다. 기본 시작 메뉴와 같은 동작입니다.

일반 앱처럼 바탕 화면에 계속 띄워 두고 싶다면 항상 위에 표시를 끄고 상시 표시를 켜세요.

타일을 끌어 위치를 바꾸고, 그룹 제목을 끌어 그룹 전체를 옮겨 보세요. 부드럽고 매끄럽게 움직이며 기본 시작 메뉴와 같은 방식으로 동작합니다.

타일 벽의 가장자리를 끌어 크기를 조절하고, 화면 가장자리로 끌어가 전체 화면과 창 모드를 매끄럽게 전환할 수 있습니다.

바탕 화면 네 모서리를 모두 기준점으로 쓸 수 있어 기본 시작 메뉴보다 자유롭습니다.

## 더 강력한 기능

타일로 파일, 폴더, 바로 가기, 웹 페이지는 물론 Steam처럼 시스템에 등록된 앱 프로토콜 링크도 열 수 있습니다.

프로그램, 디렉터리, 파일, 웹 사이트를 한 타일 벽에 모아 나만의 통합 실행 공간을 만들 수 있습니다.

타일 벽에서 마우스 오른쪽 버튼을 눌러 새 타일을 만들거나 파일 탐색기의 클래식 오른쪽 클릭 메뉴를 사용할 수도 있습니다.

빠르게 설정하고 싶으신가요? 가져오기 페이지에서 여러 원본의 타일을 가져와 자동으로 필터링하고 그룹으로 묶어 줍니다. 일일이 오른쪽 버튼을 눌러 추가할 필요가 없습니다. (시작 메뉴에서 가져오기는 완료되었고, 더 많은 원본은 개발 중입니다.)
