## **부활하라! 나의 타일이여!**

**TileWall**은 이미지, 앨범, 퍼즐 기능을 원하는 대로 꾸밀 수 있는 독립형 타일 런처입니다. Windows 11에서 익숙한 Windows 10 타일과 시작 메뉴 경험을 되살립니다.

Windows 10과 Windows 11을 지원하며 x64 PC에서 사용할 수 있습니다. 앱 UI는 중국어(간체)와 영어만 지원합니다.

**TileWall**은 Windows 네이티브 UI 프레임워크 WinUI 3로 개발되어 시작 메뉴와 타일 벽을 재현합니다. 기본적으로 **Win + 백틱 키**로 호출하며, Windows 시작 메뉴와 독립적으로 작동합니다. Windows Shell을 교체하거나 기존 사용 습관을 바꿀 필요가 없습니다.

[**Microsoft Store**](https://apps.microsoft.com/store/detail/9NZZN35FDB0C?cid=DevShareMCLPCS)에서 설치하거나 [포터블 압축 파일](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest) 또는 [EXE 오프라인 설치 패키지](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest)를 다운로드할 수 있습니다. 포터블 버전은 압축을 풀면 바로 실행할 수 있으며, 세 가지 배포 방식 모두 현재 사용자 계정의 타일 벽 데이터를 함께 사용합니다. 데이터 위치는 `%LOCALAPPDATA%\TileWall`입니다.


## 퍼즐, 이미지와 앨범

이미지를 직접 나누고 정렬할 필요 없이 한 페이지에서 모두 해결하세요!

이미지를 대상으로 설정하면 **TileWall**이 이미지 타일을 자동으로 사용합니다.

사용 가능한 이미지가 들어 있는 폴더를 대상으로 설정하면 **TileWall**이 앨범 전환을 자동으로 켭니다. 폴더에 이미지를 추가하거나 삭제하면 편집 페이지를 수정하지 않아도 앨범이 자동으로 업데이트됩니다.

일반 바로 가기 타일도 이미지나 앨범으로 모양을 바꿀 수 있습니다.

퍼즐 모드에서는 미리 보기의 내부 격자선을 왼쪽 또는 오른쪽 클릭해 나누거나 합칠 수 있습니다. 마우스 휠을 굴리면 이미지 확대율을 빠르게 조절할 수 있습니다.

## Windows 10 시작 메뉴 경험 재현

<kbd>Win</kbd> + <kbd>&#96;</kbd>(숫자 1 왼쪽의 키, Shift 없이)을 누르면 타일 벽이 나타납니다. 기본 설정에서는 실행 대상이 성공적으로 시작되거나 포커스가 다른 곳으로 이동하면 타일 벽이 자동으로 접힙니다.

일반 앱처럼 바탕 화면에 계속 띄워 두고 싶다면 항상 위 표시를 끄고 상시 표시를 켜세요.

타일을 끌어 위치를 조정하고, 그룹 제목을 끌어 그룹 전체를 옮기세요. 원하는 대로 타일 벽을 꾸밀 수 있습니다.

타일 벽 가장자리를 끌어 창 크기를 조절할 수 있으며, 설정에서 전체 화면과 창 모드를 전환할 수도 있습니다. 전체 화면에서는 조절 가능한 가장자리나 모서리를 안쪽으로 끌면 창 모드로 돌아옵니다.

바탕 화면의 네 모서리를 모두 기준점으로 사용할 수 있어 기본 시작 메뉴보다 자유롭습니다.

원하는 배치가 완성되면 설정에서 **레이아웃 잠금**을 켜 타일 벽의 표시 크기, 기준점, 그룹 위치를 고정할 수 있습니다. 개별 타일은 기존 그룹 안에 공간이 있는 자리로 계속 옮길 수 있으며 다른 내용을 밀어내지 않습니다. 다시 시작한 뒤에도 잠금 상태가 유지됩니다.

설정에서 **시스템 시작 메뉴 대체(실험)**를 켜면 Windows 키를 누르거나 시작 버튼을 클릭해 TileWall을 열 수 있습니다. 이 옵션은 언제든지 끄고 기본 시작 메뉴를 다시 사용할 수 있습니다.

## 더 강력한 기능

타일은 파일, 폴더, 바로 가기, 웹 페이지 등 다양한 항목을 실행할 수 있으며, Steam처럼 시스템에 등록된 앱 프로토콜 링크도 지원합니다.

프로그램, 폴더, 파일, 웹 사이트를 한 타일 벽에 모아 나만의 완벽한 시작 공간을 만들 수 있습니다.

타일 벽에서 마우스 오른쪽 버튼을 눌러 새로 만들거나 파일 탐색기의 클래식 오른쪽 클릭 메뉴를 사용할 수 있습니다.

자동 아이콘은 프로그램, 바로 가기, 앱 패키지의 네이티브 고해상도 리소스를 읽고 화면에 맞는 크기를 선택합니다. 자주 쓰는 웹 사이트에는 오프라인 아이콘도 함께 제공됩니다. 원하는 모양으로 꾸미고 싶다면 언제든 아이콘을 직접 바꿀 수 있습니다.

빠르게 배치하고 싶으신가요? 가져오기 페이지에서 시작 메뉴, 바탕 화면, 설치된 앱, 시스템 기능, 타일 벽 파일의 항목을 한꺼번에 추가할 수 있습니다. 필터링, 자동 필터링, 그룹화도 지원하므로 하나씩 오른쪽 클릭해 추가할 필요가 없습니다.

선택한 타일, 퍼즐, 앨범을 공유용 ZIP 파일로 내보내거나 다른 사람이 공유한 타일 벽을 가져올 수 있습니다.

고정을 해제한 타일은 TileWall 휴지통으로 이동합니다. 필요할 때 “가져오기 및 내보내기 → 휴지통”에서 복원을 선택할 수 있습니다.

시작 메뉴가 그립다면 설정에서 **메뉴형 시작**을 켜세요. 목록과 타일이 나란히 표시되고 양쪽에서 같은 항목에 접근할 수 있습니다.
