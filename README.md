# TileWall for Win11

> 一面随时呼出的 Win10 风格磁贴墙：以固定网格组织你的启动入口，磁贴组共享一张画布并同步翻转；独立于系统开始菜单，不接管 Win 键。

**状态：早期开发中（未正式发布）**。当前版本可用于日常试用，观感参数与动画时长仍待校准。

## 功能一览

- **磁贴墙**：快捷键（默认 `Win + ~`）或双击托盘图标呼出，屏幕左下角弹出；Esc / 点击墙外收起，离开即走。
- **独立磁贴**：程序、文件夹、文件、网址都能钉上；点击即启动，交给 Windows 打开，参数与工作目录完整保留。
- **拼图组**：一张大图铺满整组磁贴（共享画布），画墙 / 拆墙自由切分矩形分区；多张图片 60 秒轮播，Win10 式逐块同步翻转。
- **自由布置**：拖动自动腾位（预览即结果）、组整体移动、容量不足明确提示、Ctrl+Z 撤销。
- **添加入口**：空白处右键新建、从开始菜单批量导入、资源管理器右键「添加到 TileWall」（需安装版）。
- **时间日期组件**、**模态设置窗**（快捷键 / 登录自启 / 关于）。

## 系统要求

- Windows 10 22H2 或 Windows 11
- 安装版（MSIX）开箱即用；便携版解压即用，无需安装任何运行时

## 快速上手

1. 启动后驻留托盘；按 `Win + ~` 或双击托盘图标呼出磁贴墙。
2. 空白处右键 →「新建磁贴」选择目标，或「从开始菜单导入」批量钉入。
3. 拖动排列、右键编辑属性（大小 / 后景 / 前景 / 文字 / 链接）。
4. 托盘右键 → 设置：可改快捷键、开启登录后启动。
