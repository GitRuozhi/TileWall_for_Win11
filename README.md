# TileWall for Win11

TileWall 是面向 Windows 10 22H2 和 Windows 11 的独立磁贴启动墙。它以 Windows 10 开始菜单为视觉与分组参考，用磁贴组织程序、文件、文件夹和网址；系统开始菜单与 Win 键照常工作。

**当前源码：0.2.2 / 0.2.2.0，已完成必要隔离验收。** 墙面标题/网格/设置及主题背景改动见[已完成计划](Plan.md)与[验收摘要](artifacts/settings-and-header-2026-10-13/evidence/validation-status.md)。恢复默认仅重置设置并保留墙面内容；Win10模拟Mica延后，本轮使用纯色占位，Win11原生Mica保留但本机未验。正式Release、正常实例与快捷方式均未替换。

## 目标体验

- **真正的磁贴分组**：每块普通磁贴、每个完整拼图和时间日期组件都属于一个有名或无名分组。组名占一整行48 DIP，文字在下半部；单击拖动整组、双击改名，右侧把手已移除。拖成员可在组内或跨组排布，拖到组间空白会建立新组。最后一个成员移出后，空组自动消失。分组不会嵌套。
- **普通磁贴与拼图区分**：普通磁贴各有自己的目标和外观。拼图是一张共享画布分成多个矩形块，整幅拼图只有一套属性和一个可选目标；它作为完整对象加入分组，分块不是独立应用。
- **一屏可见**：每栏八个基础格，墙面不滚动、不翻页，不把对象藏在屏外。移动或新增内容放不下时明确提示并恢复原布局。
- **图片与图标**：拼图支持单图、多图和文件夹图片、逐图调整、模糊补底、60 秒轮播和同步翻转。普通磁贴可用目标程序原始的多尺寸 EXE 图标，也可选择自定义图片或明确不显示图标。图标展示不改变原快捷方式的启动行为。
- **主题与背景**：主题跟随系统或选亮/暗色；墙面风格Windows10方角、Windows11小圆角。背景Acrylic/Mica/自定义图片，默认15%透明；Acrylic失活回退Mica，Win10当前纯色占位。网格默认关闭，打开后白格90%透明；系统减效或高对比时使用可读实色。
- **窗口设置**：墙可锚定工作区四角，默认左下，全屏暂不可选；永在最前默认开启，常驻显示默认关闭。开启常驻后，已显示的墙失焦或启动目标仍留在屏幕，Esc/显隐热键仍可收起；登录启动只驻留托盘，不自动弹墙。语言可跟随系统或选中文/英文。两列设置分外观、常规、关于但不显示组标题；恢复默认仅重置设置，保留墙内容。

目标还包括托盘与快捷键呼出、从开始菜单批量导入、资源管理器右键添加、属性编辑、拖放预览、撤销和时间日期组件。程序、网址等入口交给 Windows 按托管的 `.lnk` / `.url` 打开，保留快捷方式的参数、工作目录和原有目标语义。

## 开发状态

实现已形成新的 `WallDocument` / `WallStore` Core 存储与 `WallSession` 编排，并在 `Views/`、`Graphics/`、`Shell/` 中承载新 UI、图像与系统接线；旧 UI、旧图像引擎和旧格式存储代码已从正式源码删除，本机自动化与真实输入回归已完成，UAC 取消和实际登录由用户确认人工测试完成。新 schema 不迁移旧布局。仅能明确识别为旧 schema 1 的应用自有状态允许受限重置；schema 2 损坏、未来版本或来源不明残留必须保留并阻断，不能静默建空墙。新格式包含事务、撤销和恢复协议。日常数据根为 unpackaged `%LOCALAPPDATA%\TileWall`，packaged 使用 `ApplicationData.Current.LocalFolder`，二者不互读；外部原件只读。完整手动备份/还原须在应用退出后复制整个对应数据根，应用内备份界面不在范围内。

普通用户发行仍待正式授权文本定稿、MSIX 可信签名及安装路径验收。当前便携 ZIP 与未签名 MSIX 已构建并完成内容核验；未签名包仅用于隔离验证，不能据此声称已验证安装。Windows 11 未覆盖，不能宣称双平台验收。
