## **Come back to life, my tiles!**

**TileWall** is a standalone tile launcher for Windows 10 version 22H2 (build 19045) and Windows 11 on x64 PCs. It brings back the familiar Windows 10 tile and Start menu experience, with room to make the wall your own using pictures, albums, and puzzles.

Built with WinUI 3, **TileWall** opens with **Win + the grave-accent key** (left of 1 on a US keyboard, without Shift) by default. Arrange your favorite shortcuts in groups and drag them into place. By default, the wall hides when you successfully launch an item or move focus elsewhere; you can also keep it visible on your desktop. Resize the window, switch to full screen, anchor it to any corner, or show a menu-style app list beside your tiles.

TileWall runs alongside Windows and does not replace Windows Shell or force you to change your usual habits.

## Puzzles, pictures, and albums

No more splitting and aligning pictures by hand. Do it all on one page!

Click **Split tiles**, then left- or right-click the dotted lines in the preview to split or merge sections. Scroll the mouse wheel to quickly adjust the image zoom.

Set a picture as the target, and **TileWall** automatically displays it as a picture tile.

Set a folder containing supported pictures as the target, and **TileWall** automatically turns it into a rotating album. Add or remove pictures in the folder, and the album updates automatically.

You can also customize an ordinary shortcut tile with a picture or an album.

## Recreate the Windows 10 Start menu experience

Press <kbd>Win</kbd> + the grave-accent key (left of 1 on a US keyboard, without Shift), and the tile wall appears. Successfully launch a program or move focus elsewhere, and by default the wall folds away, just like the native Start menu.

Want it to stay on your desktop like a regular app? Turn off **Always on top** and turn on **Stay visible**.

Drag tiles to rearrange them, or drag a group title to move the whole group. Smooth as silk, just like the native Start menu.

Drag the edge of the tile wall to resize it. Drag it to the edge of the screen to switch seamlessly between full-screen and windowed modes.

All four desktop corners can be anchors, giving you more freedom than the native Start menu.

You can also turn on **Replace system Start** in Settings. Press the Windows key or click a Start button to open TileWall; turn the option off whenever you want to return to the native Start menu.

## More features

Tiles can open programs, folders, files, shortcuts, and websites, as well as app protocol links registered with Windows, such as Steam links.

Put your favorite programs, folders, files, and websites on one wall to make your own all-in-one launchpad.

Create tiles from the wall’s right-click menu or use the classic File Explorer context menu to add a file or folder.

Want to set things up quickly? The import page can add items in batches from the Start menu, desktop, installed apps, Windows system features, and wall share files. Filter the list, let TileWall filter and group items for you, and skip adding them one at a time.

Export selected tiles, puzzles, and albums as a ZIP share file. Unpinned tiles go to TileWall’s Recycle Bin, where you can restore them when needed.

If you miss the Start menu too, turn on **Start menu list** in Settings. The list and tiles appear side by side, giving you access to the same launchable items.
