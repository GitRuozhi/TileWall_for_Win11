## **Come back to life, my tiles!**

**TileWall** is a standalone tile launcher with customizable pictures, albums, and puzzles, bringing the familiar Windows 10 tiles and Start menu experience back to Windows 11.

Supports Windows 10 and Windows 11 on x64 PCs. The app interface is available in Simplified Chinese and English.

Built with the native Windows UI framework WinUI 3, **TileWall** recreates the Start menu and tile wall. Open it with **Win + the grave-accent key** by default. It works independently of the system Start menu, so you can keep Windows Shell and your usual habits.

Install from the [**Microsoft Store**](https://apps.microsoft.com/store/detail/9NZZN35FDB0C?cid=DevShareMCLPCS), or download the [portable archive](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest) or [offline EXE installer](https://github.com/GitRuozhi/TileWall_for_Win11/releases/latest). Extract the portable version and run it directly. All three editions share the current user's tile wall data at `%LOCALAPPDATA%\TileWall`.


## Puzzles, pictures, and albums

No more splitting and aligning pictures by hand. Do it all on one page!

Set a picture as the target, and **TileWall** automatically makes it a picture tile.

Set a folder containing supported pictures as the target, and **TileWall** automatically turns it into a rotating album. Add or remove pictures in the folder, and the album updates automatically, with no changes needed in the editor.

You can also customize an ordinary shortcut tile with a picture or an album.

In puzzle mode, left- or right-click the internal grid lines in the preview to split or merge sections. Scroll the mouse wheel to quickly adjust the image zoom.

## Recreate the Windows 10 Start menu experience

Press <kbd>Win</kbd> + <kbd>&#96;</kbd> (the key to the left of 1, without Shift), and the tile wall appears. By default, it hides after you successfully launch an item or move focus elsewhere.

Want it to stay on your desktop like a regular app? Turn off Always on top and turn on Stay visible.

Drag tiles to rearrange them, or drag a group title to move the whole group. Arrange the wall to suit the way you work.

Drag the wall's edges to resize the window, or switch between full-screen and windowed modes in Settings. In full screen, drag a resizable edge or corner inward to return to windowed mode.

All four desktop corners can be anchors, giving you more freedom than the native Start menu.

Once you're happy with your layout, turn on **Lock layout** in Settings to keep the wall's visible size, anchor, and group positions fixed. Individual tiles can still move into empty space in existing groups where they fit, without pushing other content aside. The lock stays on after a restart.

You can also enable **Replace system Start (experimental)** in Settings to open TileWall with the Windows key or a click on the Start button. Turn the option off whenever you want the Windows key and Start button to open the native Start menu again.

## More features

Tiles can open files, folders, shortcuts, and websites, as well as app protocol links registered with Windows, such as Steam links.

Put your programs, folders, files, and websites on one wall to make your own all-in-one launchpad.

Create tiles from the wall's right-click menu or use the classic File Explorer context menu.

Automatic icons can use native high-resolution resources from programs, shortcuts, and app packages, selecting a suitable size for display. Offline icons for popular websites are included too. Prefer your own look? You can always choose a picture yourself.

Want to set things up quickly? The import page can add tiles in batches from the Start menu, desktop, installed apps, Windows system features, and wall files. Search the list, let TileWall filter and group items for you, and skip adding them one at a time.

Export selected tiles, puzzles, and albums as a ZIP share file, or import a tile wall shared by someone else.

Unpinned tiles go to TileWall's Recycle Bin. Restore them whenever you need them from Import and export → Recycle Bin.

If you miss the Start menu too, turn on **Start menu list** in Settings. The list and tiles appear side by side, giving you access to the same launchable items.
